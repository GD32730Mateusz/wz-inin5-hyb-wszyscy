# Zasady współpracy – Przewodnik po stolicach Europy

## Branch naming
- Format: miasto-imie, np. reykjavik-mateusz

## Tworzenie Issue
- Zakładaj nowe przed każdą większą zmianą
- Oznaczaj: `feature`, `bug`, `enhancement`

## Pull Request
- Każdy PR powinien mieć: opis, link do Trello, screen jeśli coś wizualnego
- Przypisz siebie jako autora
